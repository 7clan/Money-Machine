# MONEY MACHINE V3 — REBUILD THE CONTENT ENGINE AROUND REAL YOUTUBE PRODUCTION

You are working inside the EXISTING MONEY MACHINE repository with filesystem, terminal, browser, and execution access.

The application already has working infrastructure, UI, pipeline stages, YouTube connectivity, and existing video-generation code.

Your job is **NOT** to rebuild the dashboard.

Your job is to **replace the weak content-generation philosophy with a genuinely competent autonomous YouTube production system.**

---

# THE CURRENT PROBLEM

The current generation pipeline effectively does:

```text
topic
→ generic AI script
→ several scenes
→ one AI image per scene
→ Ken Burns zoom
→ crossfade
→ captions
→ AI voice
→ export MP4
```

This technically creates a video.

It does **NOT** create a good YouTube video.

The result looks like generic AI-generated slideshow content.

Do not improve this by merely adding:

```text
more transitions
more zoom
more captions
more AI images
more lower thirds
more sound effects
```

That is polishing the wrong architecture.

The entire production reasoning system must change.

# PHASE 10 — STORY FIRST

Scripts must be stories, arguments, demonstrations, or experiences.

Not Wikipedia articles read aloud.

Ban generic AI openings such as:

```text
Welcome back
In today's video
Today we are going to
Let's dive in
Without further ado
You won't believe
Here are five reasons
In conclusion
```

unless they genuinely fit the format.

Open with something that creates a question.

Possible mechanisms:

```text
contradiction
consequence
mystery
visual event
surprising fact
character conflict
problem
before/after
experiment
unexpected result
```

Example:

BAD:

```text
Today we're discussing Nokia.
```

BETTER:

```text
In 2007, Nokia sold nearly half of the world's mobile phones.

Six years later, its phone business was effectively finished.

How does the biggest phone company on Earth collapse that quickly?
```

# PHASE 11 — VIEWER QUESTIONS

The story engine must continuously understand:

> What question is currently inside the viewer's head?

Every section should:

```text
answer one question
while naturally creating another
```

Example:

```text
HOOK:
How did Nokia collapse?

SECTION 1 ANSWERS:

NEW QUESTION:

```

This prevents article-like scripts.

# PHASE 33 — NEVER INVENT A “SAFE CLIP LENGTH”

There is no:

```text
5-second rule
10-second rule
30-second rule
```

that automatically makes copyrighted footage safe.

Never encode such a rule.

For every copyrighted excerpt evaluate:

```text
Why is it necessary?

Is the clip itself being analyzed?

Is substantial original commentary present?

Does it substitute for the original?

Could safer media communicate the point?

What is the copyright risk?

What is the reused-content risk?
```

Maintain separate:

```text
COPYRIGHT_RISK
REUSED_CONTENT_RISK
INAUTHENTIC_CONTENT_RISK
```
